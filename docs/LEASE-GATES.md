## 时间与恢复的责任划分

- Docker 报告：持久事实与当前配置绑定，不因时间独立失效。旧 `expiresAt` 不延长、原报告不改；管理 DTO 日期为 null。原接口保留其历史输入，不新增消费者开关。
- Node：Portainer 身份/版本/容量真实观测；45s进入下一批、10s循环、<120s可用。报告过期不再阻止探测；失败/不匹配仍 degraded，实际匹配回来自动 healthy。
- Runtime disk：认证读取 DockerRootDir 的文件系统剩余量；30s不是能力报告TTL，与 Node 在线保护不同故障。下一次健康采样自动恢复，不需人工复测或 disabled。
- observed_host：原生物理机器的人/压力/占用，boot/session/controller epoch和≤30s新鲜性；不是 Runtime心跳替身。正式观察模式不因修改Runtime配置悄悄变回人工保守模式。
- 已有 lease：报告日期不触发撤销；原 lease TTL、profile撤销、运行完整性和明确归还照旧。unknown create/cleanup 保留占用与恢复日志，超时不宣布未执行。
