# 下一阶段：全自动家庭计算节点接入

2026-11-05。用户确认首发采用家庭局域网或已有 VPN；新 Mac / Windows 通过前端生成的一次命令，自动安装并常驻 Host / Runtime Agent、准备后端和默认模板，必要重启后继续原安装。不是安装 Agent 后让用户回到手工配置。

## 当前收口

- Windows 默认开发模板已重建为 guest 管理员，真实 SSH 和受保护文件写入/删除、正常资格、验证发布通过；旧普通用户导出已删除，临时栈及认证关闭。
- Windows 的 Vesta 范围是 CLI；旧 Temporal 加载未就绪观察不再作为本轮全应用门槛，也不据此判定上游不支持。
- Ubuntu ARM 的 Vesta / Prism CLI 与真实服务生命周期、既有 Windows CLI 通过项均保留，不重跑。两个旧 Windows 取消用例失败不被新模板倒写。

## 当前唯一平台交付主线

按照 [正式交付核查](RELEASE-READINESS-2026-11-05.md)连接前端命令、发行安装包、身份、常驻服务、自动后端/模板、跨机 SSH、资格和试租回收。复用现有管理 API、账本和 Provider；不另建调度或任务框架。

先完成这条真实流程，再用一台 Mac ARM 和一台 Windows x64 验证新接入、必要中断续接和可分配结果。主机在线与可分配分别呈现，失败保留真实阶段；不靠放宽 Docker 隔离、删除未知 Claim 或把旧证据时间刷新成新资格来显示成功。

同一正式部署的混合目录、共享主机预算和持续运行也随接入链验证。历史临时 URL / ID 不直接当生产配置。现有备份恢复、租约和回收的有效证据复用，只验证本次真正改动的连接。

互联网异地组网、云计费、额外业务平台矩阵、VM 快照池后置。当前还不能按“全自动新主机接入”范围宣称正式上线。
